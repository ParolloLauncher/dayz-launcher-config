# The FrostlinerZ Launcher

Official desktop launcher for **The FrostlinerZ (Namalsk)** DayZ community server.

---

## Features

* ### Direct Server Connection
  Automatically validates your DayZ installation (`DayZ_x64.exe`), verifies required Steam Workshop mods, and launches the game via BattlEye (`DayZ_BE.exe`) straight into the server.

* ### Live Server Status
  Displays online player count, map, in-game time, and ping, with silent background auto-refresh every 5 minutes and a manual refresh option.

* ### Restart Countdown Timer
  Live countdown to the next scheduled server restart (`01:00, 04:00, 07:00, 10:00, 13:00, 16:00, 19:00, 22:00` UK time) automatically converted to your detected or chosen timezone.

* ### Mod Management
  Checks installed Steam Workshop mods against the server's active mod list, highlights missing or outdated mods, and includes a **Subscribe All** button.

* ### Dynamic Content Tabs
  Loads **Announcements**, **Changelog**, **Rules**, **Guides**, **ErangelZ (WIP)**, and **Support us** directly inside the launcher.

* ### Settings & Keybinds Backup
  Dedicated Settings tab (`⚙`) for timezone selection, custom DayZ folder path, and one-click backup/restore of your DayZ profiles and keybinds (`Documents\DayZ`).

* ### Log Tools & AI Diagnostics
  * **Clear DayZ logs:** Safely removes old `.rpt`, `.log`, `.mdmp`, `.adm`, `.bidmp`, and `error_*.log` files.
  * **Pack logs (AI help):** Redacts personal info (Windows username & SteamID), packs recent crash/error logs and system specs into a `.zip` on your Desktop, and copies a ready-to-paste diagnostic prompt to your clipboard.

* ### Discord Rich Presence
  Automatically displays your current FrostlinerZ activity in Discord when the desktop client is running.

* ### Auto-Updater
  Silently checks for new launcher releases on startup and downloads/runs the `.exe` installer directly.

* ### Activity Log & Tooltips
  Scrollable bottom activity console with timestamps and custom hover tooltips across controls.

---

## Download & Installation

1. Go to the **[Releases](https://github.com/YOUR-USERNAME/YOUR-REPO/releases)** page.
2. Download **`TheFrostlinerZ-Launcher-Setup-1.0.3.exe`** (one-click installer that creates Desktop & Start Menu shortcuts).
3. Run the installer, enter your in-game nickname, and click **PLAY**.

> **Note:** If Windows SmartScreen displays a warning on first launch, click **More info → Run anyway** (standard for unsigned community `.exe` builds).
