## T4 Timed Crate
* **1x T4 Timed Crate** spawns every ~2 hours.
* **4 random locations** across the map.
* Global server notification announcing the **spawn position**.
* **10-minute countdown** before the crate unlocks.
* Global server notification upon **opening**.
* **Alarm sound** triggered when opened.
* Contains **T4 loot pool**.

## LANDROVER Replaces HUMVEE
* From now on, the **Car Terminal** will spawn a **Land Rover** instead of a **Humvee**, as it handles much better on Namalsk.
* You can still use existing **Humvee Cards** — the terminal will spawn a **Land Rover** regardless.
* **Land Rover Cards** now replace **Humvee Cards** in the loot pool.

## VEHICLE KEYS
* **Vehicle Keys** will now spawn exclusively on **non-military zombies**.
